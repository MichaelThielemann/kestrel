# Security policy

## Supported versions

Security fixes are released for the latest major version (5.x). Older majors receive no fixes; upgrade
notes for each major are in `CHANGELOG.md`.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead: on the
repository page open **Security → Report a vulnerability**. The report is visible only to the maintainer.

Include the affected package and version, what an attacker can do, and the steps or a minimal
configuration that reproduces it. Once a fix is released, the advisory is published and credits you
unless you prefer otherwise.
